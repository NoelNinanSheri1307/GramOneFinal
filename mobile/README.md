# GramOne Mobile Application UI

Comprehensive demo-ready mobile application UI for GramOne built with Flutter.

## Features & Screen Highlights (71 Screens)

1. **App Foundation**: Splash, Onboarding Carousel, 13-Language Selection, Role Selection.
2. **Authentication**: Sign In, Create Account, Forgot Password, OTP Verification, Password Success.
3. **Citizen Workflows**: Dashboard, 4-Step AI Issue Reporting, My Issues List, Issue Detail, Timeline, Evidence Capture, Gallery, Feedback.
4. **Panchayat Administration**: Admin Console, Issue Queue, Issue Review, Worker Assignment, Field Verification, Impact Cases, Projects, Sponsorships, Attendance, IoT Telemetry, Emergency SOS, Impact Analytics.
5. **Field Employee Workflows**: Worker Portal, Assigned Tasks, Work Acceptance, Field Inspection Form, Before/After Photo Upload, Completion Confirmation, Daily Attendance.
6. **CSR Partner Workflows**: CSR Portal, Corporate Profile, Opportunity Discovery, Project Detail, AI Matchmaking, Sponsorship Pledging, Active Sponsorships, Telemetry Impact Tracking.
7. **Hardware & IoT Telemetry**: Water Tank Monitor, Waste Bin Monitor, Environmental AQI, Gas Anomaly Alert, Panic Button SOS, Device Detail, Diagnostics.
8. **Notifications & Settings**: Notification Inbox & Detail, User Profile, Edit Profile, Language Switcher, Accessibility Options (WCAG AAA), App Settings, Help & Support, About.

## How to Run

Navigate to the `mobile` directory and launch:

### Web (Google Chrome)
```bash
flutter run -d chrome
```

### macOS Desktop
```bash
flutter run -d macos
```

### iOS Simulator
```bash
open -a Simulator
flutter run
```
