# database/seeds

Seed scripts (reference data such as villages, SDG mappings, default CSR
focus-area tables) will live here.

**Current state:** empty. Seeding is part of the data-model / CSP milestones and
is intentionally not implemented in the foundation. Any seed data will be
clearly marked as reference/demo data, never as fabricated real-world data.

The foundation deliberately ships **no seed scripts** to avoid any fake data
being presented as real.
