# database/migrations/versions

Alembic revision files (generated by `alembic revision`) are stored here.

The migration environment lives in `env.py` one level up; it imports the
application's SQLAlchemy metadata from `backend/app` and reads `DATABASE_URL`
from the environment.

**Current state:** revision `e457a57f8afe` *"add assigned_to and impact case
workflow states"* (on top of `94138b2c890c` *"add core domain schema"*) adds the
Panchayat `assigned_to` columns to issues/impact_cases and extends the
`impact_case_status` enum with `assigned`/`in_progress`. Applied with:

```
cd backend
alembic upgrade head
alembic current
```
